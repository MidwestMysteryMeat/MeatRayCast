# templates/

Per-genre starter definitions for MeatRayCast. The registry, the base-chain
inheritance and the validation live in `meatray.game.template`; this directory
documents each genre and how it maps to the engine's systems.

See `docs/TEMPLATES.md` for the catalogue and the subset tree, or run
`template` in the in-game console to list them and switch the demo to one.

Playable now: `fps`, `tdm`, `coop`, `crawler`.
Scaffolds (config set, genre layer yours to build): `rpg`, `turnrpg`, `mmo`, `vn`.
